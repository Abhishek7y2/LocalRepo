# Calculator UI (HTML + CSS + JavaScript)

A simple and responsive Calculator built using **HTML, CSS, and JavaScript** as part of my frontend fundamentals revision.  
This project helped me revise DOM manipulation, event handling, and basic calculator logic.

---

## 📌 Features

- ✅ Clean and modern Calculator UI
- ✅ Supports basic operations:
  - Addition (+)
  - Subtraction (-)
  - Multiplication (×)
  - Division (÷)
- ✅ Clear / Reset buttons
- ✅ Responsive layout (works on desktop & mobile)
- ✅ JavaScript-based calculation logic

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
